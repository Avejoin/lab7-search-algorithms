# Lab7Search

Лабораторная работа № 7 по МДК 05.02 «Реализация алгоритмов поиска. Отладка приложения».
Оконное приложение на C# (.NET 8, Windows Forms). Каждой задаче соответствует отдельная вкладка.

## Что реализовано

| Задача | Описание |
|--------|----------|
| 1 | Поиск вхождения строки в тексте: выводятся все слова, где она встречается. Есть проверка ввода и сообщения о результате |
| 2 | Наименьший элемент упорядоченного массива |
| 3 | Элементы массива, большие 30 |
| 4 | Числа массива, кратные 3 |
| 5 | Числа массива, кратные 4 |

В задачах 2–5 используются три метода: линейный, бинарный и индексно-последовательный поиск. Для каждого метода выводится число сравнений.

## Требования

- Windows 10 или 11
- Visual Studio 2022 или новее с рабочей нагрузкой «Разработка классических приложений .NET»
- .NET 8 SDK

## Как запустить

1. Скачайте репозиторий: **Code → Download ZIP** и распакуйте архив, либо выполните `git clone`.
2. В Visual Studio выберите **Файл → Открыть → Проект или решение** и откройте файл `Lab7Search.csproj`.
3. Нажмите **F5** (или зелёную кнопку ▶).
4. Откроется окно с вкладками «Задача 1»–«Задача 5». В задачах 2–5 нажмите «Выполнить», в задаче 1 введите текст и строку и нажмите «Найти».

Массив A по умолчанию: 2, 5, 8, 12, …, 60 (20 элементов, по возрастанию). Его можно заменить своим упорядоченным массивом целых чисел через запятую. Если массив неупорядочен или содержит не числа, программа выведет сообщение об ошибке.

## Структура проекта

- `Program.cs` — точка входа
- `MainForm.cs` — форма, ввод и вывод данных
- `TextSearch.cs` — задача 1 (поиск подстроки)
- `ArraySearch.cs` — задачи 2–5 (линейный, бинарный, индексно-последовательный поиск)
